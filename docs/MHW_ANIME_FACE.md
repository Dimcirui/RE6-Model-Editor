# 动漫脸表情适配（MHWI，2026-10-04，进行中）

目标：一套通用于动漫风格脸的猎人面部动画（pl_face.lmt 及过场 pl000_*.lmt），驱动的是
Modding Toolkit「MMD 形态键转表情权重」生成的 8 个组（上下眼皮 321/325/334/338、上下唇 381/388、嘴角 384/385）。

## 工具
- `tools/mhw_lmt_anime.py`：重映射。每根配置骨骼的位置值 `new = anchor + soft_limit(G · (old − neutral))`；
  `neutral` = 动画里该骨骼的中位姿势，`anchor` = face000 的绑定姿势（动漫脸模组基于 face000 做）；
  `G` 每个轴、每个方向一个 3 向量（增益 + 斜度），按带符号位移相乘；超出动漫参考 1.3 倍处平滑收住。
  `"rotation": "identity"` 的骨骼，旋转轨道改为常量单位四元数（type 2、size 0），只改轨道头。
  逐字节校验（`--check`），文件大小不变。
- `tools/mhw_anime_calibrate.py`：从参考脸算配置 `tools/data/mhw_anime_face.json`。
  输入 `tools/data/anime_ref/`：`anime_keys.json`（各参考脸各形态键在各区域外表面顶点的加权平均位移，Blender 导出）、
  `face_rest.json`（骨骼父空间朝向）、`f_face000_rest.json`（face000 绑定姿势）。
  猎人侧按每个轴第 2/98 百分位当"典型大表情"，参考侧 MMD 元音与 VRChat 口型合并取中位数。
  `OVERRIDES` 是看图后的手动决定（见下）。
- `tools/blender/mmd_face_weights_v2.py`：嘴部权重的改进原型（外表面百分位归一化 + 口腔内部按深度衰减），眼皮保持工具原做法。

## 关键事实
- 所有玩家脸（含联动 face003）共用一个 pl_face.lmt，位置是绝对值；各脸绑定姿势不同（最多差约 7 cm），
  LMT 中性表情落在各脸平均位置附近。f_mesh Armature 的面部骨骼 = face003，不能当基准。
- 猎人中性表情 ≠ 绑定姿势：眼皮比 face003 绑定高 ~0.5 cm，嘴角外扩 ~0.5 cm、靠后 ~0.25 cm（相对 face000）。
- 原版有些片段把嘴角、嘴唇旋转 15–27°（031 只转左嘴角）。动漫脸这些区域权重范围大，会被斜着撕开 → 旋转归零。
- 嘴角下拉 + 上唇上抬会把低面数动漫嘴撕开 → 嘴角竖直方向压到 0.2。

## 手动决定（用户确认）
- 嘴部幅度不用像猎人那么夸张，能辨认即可；张嘴压得狠。
- 上唇几乎不动（增益 ×0.5，最多抬 0.3 cm）；嘴唇前后 0.15–0.2；嘴角保持水平。
- 口腔内部不能完全排除（前缘贴合嘴唇），按深度衰减。

## 预览（Blender）
- MHW-Free-HyperKinetics `freehk.import_lmt`（tether 到骨架）会把骨架对象位置归零、可能"接地"抬高骨架。
- 场景：`f_face000 Armature` + H0_* 原版头；VRChat / MMD 参考脸已平移到 face000 模型空间并绑定。

## 嘴部放大与眼睛（2026-10-04）
- 嘴部 ×2（`MOUTH_SCALE`）：模组通常把嘴部权重削到 0.4–0.6，权重只能往下调，所以动画给强的一端。
- 眼睛：原版眼球骨 315/328 只有旋转（65 个片段为关键帧，68 个为常量，最大约 33°；视线左右 ±0.29、上下 −0.40/+0.25），
  位置恒定。动漫眼是内凹平面 + 虹膜平移，所以把旋转换算成平移：偏移 = (rx·gx, ry·gy)，g = 骨骼前向轴（+z）经旋转后的方向，
  rx 1.2 / ry 0.9 cm，上限 0.45 / 0.40 cm，旋转归零。关键帧片段的位置轨道改成 16 位关键帧，缓冲追加在文件末尾
  （pl_face 增大约 181 KB；HyperKinetics 能正常读）。
- 旋转解码 `tools/mhw_lmt_rot.py`：移植自 HyperKinetics（类型 2/6/7/11/12/13/14/15），与其解析器逐键对比误差 5e-7。

## 四档闭眼与左右对称（2026-10-04）
- 1 倍 = 猎人一次正常眨眼（mhw_lmt_lid 的 T→C）刚好让 Shinano（场景 Body）闭眼：上眼皮边缘（权重≥0.95 的顶点）
  下移 2.82、后移 0.76、向鼻侧 0.19 cm（`tools/data/anime_ref/lid_ref.json`），增益约 4.2。`--lid-scale` 出 0.8/1/1.2/1.5 四档。
- 左右不对称：原版左眼皮张开时比右边高 ~0.1 cm，单次眨眼也有几毫米差，动漫增益（~4 倍）把它放大。
  改为每侧从自己的张开高度 T 量起，并在双眼同时眨时把两侧闭合比例往平均拉（差超过 0.9 时不拉，保留单眼眨和单侧眯眼）。
- 产物：`out/mhw_anime/x{0.8,1,1.2,1.5}/nativePC/`，每档 141 个 LMT（与眨眼包同一批文件），配置 `out/mhw_anime/config_x*.json`。
